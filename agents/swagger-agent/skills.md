# Swagger Agent Skills

The `swagger-agent` possesses specialized expertise in the following areas:

## Core Technologies & Libraries

- **swagger-jsdoc**: For integrating Swagger/OpenAPI definitions directly into code comments.
- **swagger-ui-express**: For serving auto-generated API documentation via a web interface.
- **OpenAPI 3.0 Specification**: Deep understanding of the OpenAPI 3.0 specification for accurate and compliant documentation.
- **YAML/JSON**: Proficiency in writing OpenAPI specifications in both YAML and JSON formats.

## Documentation Best Practices

- **REST API Documentation**: Expertise in documenting RESTful API principles, including resources, HTTP methods, and status codes.
- **API Versioning**: Strategies for documenting and managing API versions.
- **Request/Response Schemas**: Defining precise data structures for API requests and responses using JSON Schema.
- **Authentication & Authorization**: Documenting various security schemes, especially JWT Bearer authentication, and refresh token mechanisms.
- **Error Handling**: Standardized documentation of API errors, including error codes, messages, and examples.
- **Examples**: Providing realistic and clear examples for requests and responses.
- **Tags**: Organizing API endpoints into logical groups using tags.
- **Reusable Components**: Leveraging OpenAPI's `components` section for schemas, parameters, responses, and security schemes to ensure modularity and reduce redundancy.
- **Security Schemas**: Defining and referencing security schemes (e.g., `BearerAuth`).
- **Middleware Documentation**: Explaining the role and impact of middlewares like rate limiting and authentication.
- **Recovery Flow Documentation**: Comprehensive documentation of password recovery, email verification, and other security-sensitive flows.

## Output Generation

- **Modular Documentation Structure**: Generating a well-organized file structure for OpenAPI definitions.
- **Complete Swagger Configuration**: Setting up `swagger-jsdoc` and `swagger-ui-express` with project-specific configurations.
- **Initial Setup & Integration**: Performing the initial setup and integration of Swagger documentation into the Express application.
- **Real-world Examples**: Providing concrete examples of how to document specific endpoints relevant to the project's authentication system.
- **Consistent Response Structures**: Ensuring documentation reflects consistent API response formats for success and error scenarios.
