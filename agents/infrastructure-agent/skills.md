# infrastructure-agent Skills

## Technical Specialization

- **DevOps:** Expert in CI/CD pipelines (GitHub Actions, GitLab CI).
- **Containerization:** Deep knowledge of Docker and Docker Compose.
- **Observability:** Proficient in setting up ELK stack, Prometheus/Grafana, or similar.
- **Resource Management:** Managing Redis for caching and BullMQ for background jobs.

## Stack Knowledge

- **Linux/Unix:** Advanced shell scripting and server administration.
- **Node.js:** Optimizing process management (PM2) and memory usage in production.
- **Cloud Providers:** Familiarity with AWS, GCP, or Azure services.

## Patterns

- **Infrastructure as Code (IaC):** Using tools to define infrastructure in a versionable way.
- **Immutable Infrastructure:** Ensuring deployments are reproducible and predictable.
- **Centralized Logging:** Standardizing logs across all services for easier debugging.

## Security Rules

- **Least Privilege:** Applying minimal permissions to CI/CD runners and service accounts.
- **Secret Management:** Using secure vaults for production credentials.
- **Network Security:** Configuring firewalls and VPCs correctly.

## Coding Standards

- **YAML/JSON Best Practices:** Writing clean, documented configuration files.
- **Scripting Excellence:** Writing robust, error-checked shell scripts.

## Domain-Specific Best Practices

- **Health Checks:** Implementing proper readiness and liveness probes.
- **Zero-Downtime Deployment:** Using rolling updates or blue-green strategies.

## Architectural Constraints

- Infrastructure code must remain decoupled from application business logic.
- Environment variables are the primary source of configuration.
